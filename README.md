Classroom Scoreboard 🌟

A simple, no-download star-scoring tool for classroom team games — built as a single HTML file, no installs or setup needed.

What it does Set up — type how many teams are playing. Teams — give each team a name and pick an icon from a set of animal emojis. Scoreboard — each team gets a card with big + / − buttons to add or take away stars during the game. Stars can go negative. Try it live

👉 Open the scoreboard: https://ashleytr-05.github.io/VUS-Scoreboard/

Run it locally

No build steps, no dependencies. Just download index.html and open it in any browser.

Tech

Plain HTML, CSS, and JavaScript — one file, no frameworks.
